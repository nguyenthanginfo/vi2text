Cách tạo API key cho phần "Nghe đọc" & Cài đặt thành ứng dụng trên điện thoại.

1. Lấy API key cho giọng đọc

Chỉ cần thực hiện khi muốn dùng giọng đọc tốt hơn của Google/Azure trong phần "Nghe đọc". Nếu chọn giọng "Trình duyệt (miễn phí)" thì bỏ qua bước này.

  1. Truy cập console.cloud.google.com và đăng nhập bằng tài khoản Google.
  2. Tạo một Project mới (hoặc Project có sẵn) ở góc trên cùng.
  3. (Bạn phải nhập thông tin thẻ Visa/Master mới kích hoạt được)
  4. Vào APIs & Services → Librarytìm Cloud Text-to-Speech API và bấm Enable
  5. Vào APIs & Services → Credentials → Create Credentials → API key
  6. Copy đoạn key vừa tạo, dán vào ô Google TTS API key trong 'Cấu hình giọng đọc' của App.

Google Cloud có mức dùng miễn phí giới hạn (khoảng 1 triệu chữ/tháng) cho 'Text-to-Speech', vượt mức sẽ tính phí theo tài khoản Visa/Master đã liên kết.

  1. Truy cập portal.azure.com và đăng nhập bằng tài khoản Microsoft.
  2. Bấm Create a resourcetìm và chọn Speech (Azure AI Speech).
  3. (Bạn phải nhập thông tin thẻ Visa/Master mới kích hoạt được)
  4. Đặt tên, chọn Region (vd: Southeast Asia) và gói giá (miễn phí/trả phí).
  5. Sau khi tạo xong, mở resource vừa tạo → vào mục Keys and Endpoint
  6. Copy 1 trong 2 Key, cùng với Region, dán vào ô Azure Subscription key và Azure Region trong 'Cấu hình giọng đọc' của App.

Ô Region cần nhập đúng dạng viết liền không dấu cách, ví dụ southeastasia.

2. Cài thành ứng dụng trên điện thoại

Sau khi cài, App sẽ có icon trên màn hình chính và mở lên như một ứng dụng thông thường.

  1. Mở link này bằng Safari hoặc Chrome.
  2. Bấm nút Chia sẻ (hình vuông có mũi tên đi lên) trên thanh công cụ.
  3. Cuộn xuống, chọn Thêm vào Màn hình chính
  4. Bấm Thêm ở góc trên — icon App xuất hiện trên màn hình chính.
  1. Mở link này bằng Chrome/Edge
  2. Bấm menu 3 chấm (⋮) ở góc trên bên phải, gần thanh địa chỉ.
  3. Chọn Cài đặt ứng dụng (hoặc "Thêm vào Màn hình chính").
  4. Xác nhận xong, icon App xuất hiện trên màn hình chính.
